Everything a beginner needs

Inspired by the classic typing tutors, built for today's kids. Practice lines are made fresh every time, using only the keys learned so far.

☝️

Right finger, every key

A colour-coded keyboard and hands show which finger presses the next key, so good habits start on day one.

⭐

Small steps, gold stars

Each step is a few short lines. Accuracy earns up to three stars, and the next step unlocks as you go.

🎈

Balloon Pop

Type the word on a balloon to pop it before it floats away. It only uses keys you've learned.

🎯

Tricky keys practice

It notices which keys are slow or often missed and builds a focused drill for exactly those.

📈

Progress you can see

A speed chart for each child, plus a grown-ups' view comparing everyone. Older learners can set a speed goal.

🔒

Private by design

No accounts and no internet needed. Progress stays on your computer, and nothing is sent anywhere.

Download

No installer and no Python needed. Download the file for your computer and open it.

Windows 10 or 11

Download for Windows

Double-click LearnTyping-windows.exe. If you see "Windows protected your PC", click More info, then Run anyway.

Mac

Apple chip M1 or newer Intel

Unzip and open Learn Typing. If macOS says it "could not verify" the app, open System Settings → Privacy & Security and click Open Anyway. Not sure which chip? Apple menu → About This Mac.

Linux

Download for Linux

Extract it and run ./LearnTyping. 64-bit, Ubuntu 22.04 or newer (or similar).

Why the warning? The app isn't signed with a paid Apple or Microsoft developer certificate, so your computer can't vouch for it. You only need to allow it once. The source code is public if you'd like to check it, or run it with Python instead.
